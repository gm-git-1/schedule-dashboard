Benchmarks
  • Containment differs by industry: Druid production data: "good" containment is 80% in financial services, 87% healthcare, 93% HR/IT, 99% higher education; run the scorecard weekly against a human baseline (20:00–22:00)

How Secrets Leak Through AI Agents (and How to Stop It) — Venice AI

AI Engineer · Joshua Mo, Venice AI · uploaded 11 Oct, 10:00 PM IST · 15:22
Verdict: worth watching — short and has concrete patterns for keeping keys out of the model.
🔁 Repeat: 'agent security' — seen 6 times before. New here: keeping secrets out of the reasoning layer entirely.
How leaks happen
  • Observability logs: Traces and logs can capture prompts and secrets, so logging itself becomes a leak path (5:00–6:15)
  • Secrets in the context: The common vault → LLM → tool-call design feeds the raw secret to the model, which may echo or misuse it (6:15–7:30)
Fixes
  • Split-key custody: Encryption keys stored as separate read and write halves, so a breach (even of staff accounts) can't decrypt; use revocable handles instead of raw keys (3:45–8:45)

  • Deterministic execution layer: Inject credentials (e.g. browser logins) in a non-LLM layer; build your own agent runtime and monitor network access to stop exfiltration (11:15–13:45)
  • TEEs: Trusted execution environments can isolate the reasoning layer cryptographically; confidential tool calls still need work (13:45–15:22)
